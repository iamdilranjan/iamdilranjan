## 👨‍💻 Who Am I?

💡 **"I build AI systems that don't just execute — they reason, decide, and act."**

I'm an **AI Engineer** working across **Agentic AI, LLMs, and Retrieval-Augmented Generation (RAG)** — turning real, messy business workflows into automated systems that run in production, not just in a demo.

I enjoy turning **complex problems into self-operating systems** using Python, LLMs, and automation tools like n8n and Zapier.
